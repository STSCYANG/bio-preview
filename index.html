피부 속, 필요한 세포까지 전달합니다.

스타스테크 바이오사이언스는 피부 장벽을 지나 진피까지 유효성분을 전달하는 기술 TDS 와, 원하는 세포에 선택적으로 닿는 표적 전달 기술 T-TDS 를 개발합니다. 화장품 원료에서 병의원 스킨부스터, 신약 파이프라인까지 하나의 전달 플랫폼 위에서 사업을 넓혀 가고 있습니다.

기술 소개 파트너링 문의
TDS 각질층을 지나 진피까지 막이 유연한 전달체가 피부 장벽 사이를 변형하며 통과합니다. Penellagen® 으로 상용화를 마쳤습니다. 상용화 T-TDS 필요한 세포에만 닿는 표적 전달 전달체 표면에 표적 리간드를 더해 특정 세포에 선택적으로 닿습니다. 첫 제품 Delvene® 을 준비하고 있습니다. 2026년 12월 출시 예정 파이프라인 화장품에서 신약까지, 하나의 전달체 리드 프로그램인 국소 건선 치료제는 비임상 단계이며 IND 를 제출하지 않았습니다. 비임상 · IND 미제출

T-TDS여섯 요소가 하나의 전달체로

인지질 이중층 사이사이에 계면활성제가 섞여 들고 에탄올이 막 안팎에 머물러 탄성 있는 막을 만듭니다. 클릭 화학 결합으로 표적 리간드를 표면에 붙이고 유효성분을 안에 담아 T-TDS 를 이룹니다.

TDS탄성 에토좀이 각질층을 지나 진피까지

탄성을 부여한 에토좀은 각질층 세포 사이 지질의 유격을 벌리며 변형해 통과하고, 유효성분을 진피까지 데려갑니다.

T-TDS표적 리간드가 필요한 세포로 이끕니다

표적 리간드는 염증성 대식세포의 GLUT1, 활성화된 섬유아세포의 FAP 처럼 표적 세포 표면에 많이 발현된 단백질을 인식해 결합합니다. 이어 세포막과 융합 · 함입되며 유효성분이 세포 안으로 전달됩니다.

기술 자세히

TDS 는 유효성분을 피부 장벽 너머 진피까지 데려가고, T-TDS 는 그 위에 표적 기능을 더해 필요한 세포에만 닿게 합니다. 화장품에서 검증한 전달체를 그대로 이어받아 의약품까지 확장하는 것이 저희의 방식입니다.

각질층을 지나, 필요한 세포까지

TDS — 탄성 에토좀막이 유연한 전달체가 각질층 사이를 변형하며 통과해 유효성분을 진피까지 전달합니다. Penellagen® 으로 상용화를 마쳤습니다.
T-TDS — 표적 전달TDS 표면에 표적 리간드를 결합해 염증성 대식세포나 활성화된 섬유아세포처럼 특정 세포에 선택적으로 닿습니다.
하나의 전달체, 여러 용도리간드를 바꾸면 표적 세포가, 유효성분을 바꾸면 용도가 바뀝니다. 전달체를 새로 만들지 않습니다.
